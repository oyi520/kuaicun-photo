# 快寸照片工具

个人用的微信小程序，简称「快寸照片」。可以做标准尺寸证件照、更换底色、把图片压到指定大小。照片只在手机里处理，不上传、不登录、不用云端识别。

AppID：`wxea28a012f22ff330`

## 在微信开发者工具中打开

1. 安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html) 稳定版。
2. 用拥有这个 AppID 的微信号登录。
3. 选择「导入项目」，或点左上角「+」。
4. 目录选本仓库的根目录，也就是能直接看到 `app.json`、`app.js`、`project.config.json` 的那一层，不要选上一级。
5. AppID 填 `wxea28a012f22ff330`。`project.config.json` 里已经写好，导入时会自动带出。
6. 后端服务选「不使用云服务」。本项目没有服务器。
7. 导入后点「编译」。模拟器里应出现首页「快寸照片」，上面有三项：证件照尺寸、换底色、压缩图片。
8. 真机查看：点工具栏「预览」，用微信扫码。上传代码前，请先按 `开发说明.md` 在公众平台勾好隐私项。

基础库请用 2.25.0 或更高，建议 3.7。项目配置里写的是 `3.7.1`。如果本机工具没有这个版本，在「详情 → 本地设置」里改成已安装的 3.x 即可。

## 能做什么

- **证件照尺寸**：一寸 295×413、小一寸 260×378、大一寸 390×567、二寸 413×579、小二寸 413×531、大二寸 626×878、护照照 390×567、绘证照 330×480、简历照 295×413，以及自定义宽高。拖动、双指缩放后，按这个像素导出。
- **换底色**：在手机上把人物和背景分开，换成蓝 `#438EDB`、白 `#FFFFFF`、红 `#D32F2F`，或自己选颜色。分得不准时，用画笔涂「这是人像」或「这是背景」。
- **压缩图片**：目标 20KB、50KB、100KB、200KB 或自定义 KB。先二分 JPEG 画质，仍超标再缩小尺寸，并显示压缩前后的体积。

首页底部有一句说明：照片仅在本机处理，不上传。

## 本地检查算法

抠图、裁剪换算和压缩决策不依赖开发者工具，可以在电脑上跑：

```bash
node tests/pure.test.js
```

这些测试不上传图片，也不包含模型。

隐私权限、公众平台要勾的项目，以及不能使用深度合成的原因，写在 `开发说明.md`。小程序头像用 `images/logo.png`（1024×1024），上传位置也在那份说明里。
